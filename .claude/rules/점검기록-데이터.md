# 점검 기록 데이터 규칙 (data/ 안 파일을 다룰 때)

- 저장된 점검 기록은 수정·삭제하지 않는다. 정정이 필요하면 원본을 남긴 채
  정정 기록을 새로 추가한다(append-only). 화면에는 최신 기록을 보여준다.
- NG 판정에는 조치 메모가 반드시 있어야 한다. 화면과 저장 경로 양쪽에서 검증한다.
- 기록에는 점검자 이름·사번·연락처와 저장 시각이 들어간다.
- 점검자는 로그인 계정 없이 이름·사번을 매 점검마다 자유 입력한다(사전 등록된 목록 없음).
- 점검 기록 한 건은 TV정보·점검자·White/Red/Green/Blue/Black 5개 화면 판정을 하나로 묶은 단위다. 5개 화면 판정이 모두 있어야 저장한다.
- NG 판정에는 불량 항목(픽셀 이상/줄 이상/국소적 색 이상/화면 미출력)을 1개 이상 포함해야 한다. 조치 메모와는 별개 필수 항목이다.
- NG 조치 메모는 화면(색상)마다 개별로 남긴다. 여러 화면이 NG여도 메모를 하나로 합치지 않는다.
